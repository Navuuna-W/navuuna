# PR screenshots — Access lane

This branch is not code and is never merged into `main`. It holds the 1440 px and 390 px
screenshots that `apps/web` pull requests show in their descriptions, one folder per row
(`F3/`, `F3b/`, `G1/`, …). GitHub's command line cannot attach an image to a pull request, so
the images live here and each PR body links to them.

Every screen in these images runs on generated sample data, never a measurement of a real place.
